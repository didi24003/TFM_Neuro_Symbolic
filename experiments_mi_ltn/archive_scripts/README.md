# Archive Scripts

Esta carpeta guarda scripts Python antiguos, reemplazados o fuera del pipeline final del TFM.

Objetivo:
- conservar trazabilidad de versiones anteriores;
- evitar borrados irreversibles;
- mantener `experiments_mi_ltn/` centrado en los scripts necesarios para reproducir los resultados finales.

Criterios de archivado:
- scripts duplicados por versiones más recientes;
- scripts ligados a resultados preliminares o configuraciones antiguas;
- scripts no usados por los `.sh` del pipeline final.

Importante:
- archivar no borra resultados ni checkpoints;
- los scripts movidos siguen disponibles aquí para consulta;
- cualquier eliminación definitiva debe hacerse aparte y solo tras confirmación explícita.
