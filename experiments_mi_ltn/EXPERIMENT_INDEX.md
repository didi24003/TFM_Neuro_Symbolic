## Problemas e inconsistencias detectadas

- Hay dos familias de resultados: archivos antiguos sin sufijo (`channel_importance.csv`, `channel_importance_logic.csv`) y archivos posteriores con sufijo `30ep` (`channel_importance_baseline_30ep.csv`, `channel_importance_logic_30ep.csv`). No queda documentado en el repo cuál debe considerarse canónico.
- El README muestra un ejemplo con `--lambda-logic 0.1`, pero el checkpoint logic actual guarda `lambda_logic=1e-06`.
- El script baseline ya está preparado para guardar logs por época y curvas en futuras ejecuciones; el script de logic loss todavía no.
- `05_plot_channel_importance_pretty.py` contiene accuracies hardcodeadas (`0.6921` y `0.7114`) que no coinciden con los checkpoints actuales inspeccionados (`0.7210` baseline y `0.7153` logic).
- No hay todavía una tabla comparativa central para baseline vs logic ni para sweep de `lambda_logic`.
- Todos los resultados actuales están en una única carpeta `runs/`, lo que dificulta separar ejecuciones antiguas, ejecuciones de 30 épocas, figuras finales y artefactos temporales.
